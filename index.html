Git Concepts and Frequently Asked Questions

What is the difference between git merge and git rebase?

git merge preserves the history of both branches and may create a merge commit. git rebase reapplies commits on a new base to create a linear history and changes commit IDs.

Is git revert safer than git reset?

For shared branches, git revert is generally safer because it creates a new commit that reverses an earlier commit. git reset moves a branch pointer and can rewrite or discard history.

Can lost commits be recovered after git reset --hard?

Often yes. git reflog records earlier positions of HEAD, allowing a recovered commit to be inspected or referenced by a new branch.
